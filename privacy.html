Privacy Policy

yt-auto-upload is a personal automation tool used only by its owner.

It accesses Google Drive to read videos from a single folder chosen by the owner and to move them into an "uploaded" subfolder, and uses the YouTube Data API to upload those videos to the owner's channel.

No data is sold, shared with third parties, or stored outside the owner's own Google Drive, YouTube channel, and private GitHub repository. Credentials are stored as encrypted GitHub Actions secrets.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
